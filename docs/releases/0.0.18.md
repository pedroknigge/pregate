# Release 0.0.18

**Pregate** `v0.0.18`, core `0.0.1`. macOS ARM64 stays the stable platform. Linux and Windows archives stay experimental until native validation is recorded.

Install 0.0.18 with `pregate update`. If you come from 0.0.13 or older, also run `pregate setup` once. No project needs a step.

## Code minimization and dead-code removal

This patch release removes dead code, dead shell-guard plumbing, single-caller wrapper modules, and unused exports across `src/` without weakening any test, security boundary, or validation check:

- **Shell guard and gate:** Removed dead `harnessGated()`, `proposal()`, `importPreview()`, `BROWSER_DRIVE`, `DESKTOP_DRIVE`, `hostDrive()`, `orcaInspect()`, unused `stdinOnly` / `guideAllowed` parameters, and unused `gatedHarnesses(root)` / `shell-write` plumbing in `src/gate.ts`.
- **Dead call sites and helpers:** Removed 10 unused functions (`guideMention`, `hasTerminal`, `auditSummary`, `runnable`, `approvedLocally`, `alsoInCall`, `quotedPaths`, `batchApproval`, `namedApprovalCode`), 8 dead `delegate()` call sites, the dead `gate.redirect()` hot-path branch in `src/main.ts`, 11 unused imports, and 2 unused re-exports.
- **Module consolidation:** Inlined single-caller `src/inline-sinks.ts` into `src/shell.ts` and `src/dispute.ts` into `src/dispute-command.ts` (-2 bundled modules).
- **Export surface and catch-all baseline:** Stripped 80 unused `export` modifiers across 43 `src/` files and lowered `scripts/catch-all-baseline.txt` from 76 to 75.

## What this release does not establish

- The limits listed in the [0.0.16 notes](0.0.16.md) still apply.
- The full suite does not run on macOS in CI. macOS runs the latency and release-build jobs there, and the suite on the maintainer's machine. Linux and Windows archives stay experimental until native validation is recorded.

The [changelog](../../CHANGELOG.md) lists every change.
