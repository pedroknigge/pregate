# Release 0.0.16

**Pregate** `v0.0.16`, core `0.0.1`. macOS ARM64 stays the stable platform. Linux and Windows archives stay experimental until native validation is recorded.

Install 0.0.16 with `pregate update`. If you come from 0.0.13 or older, also run `pregate setup` once. No project needs a step.

0.0.15 was released on GitHub and was not published to npm. This version carries its changes: a plain `pregate check` does not refuse a looser contract, a contract change does not review every importer, and the agent runs the check and git itself. See the [0.0.15 notes](0.0.15.md).

This release answers two outside reviews of the project. Both said the same thing: fix the real gaps, cut surface, and say plainly which parts are validated.

## Layer rules work across a monorepo

An import of a workspace package by name was treated as an external package. `import { db } from "@acme/infra"` inside `packages/domain` was not an edge, so a layer rule that forbids domain from importing infra never saw it.

Such an import now resolves to the file in that package, through `exports`, then `module`, `main` or `types`, then `src/index`, then `index`. Workspaces are read from the root `package.json` `workspaces` and from `pnpm-workspace.yaml`. A file also uses the nearest `tsconfig.json` at or above it before the root one, so a package's own alias resolves.

One limit: the package folder must be named after the package (`@acme/infra` in `packages/infra`). A package in a folder with another name stays external, as before.

## Each pack says whether it is validated

The bundled packs were measured on eight pinned public repositories: 5,948 findings, 203 of them labeled (17 by the maintainer, 186 by an agent). A pack is validated with at least six labels and a sample precision of 70%.

Nine packs pass: architecture, clean-code, go, javascript, maintainability, mattpocock, musk, node and senior. Four measured below the bar: pstack (5 of 17), typescript (7 of 16), express (5 of 14) and vibe-proof (6 of 15). Two had too few findings to judge, and 33 reported nothing on this corpus.

Every methodology of a pack that is not validated is now `preview`. `pregate pack add` registers such a pack and selects none of its rules; `pregate pack enable <ns>/<methodology>` selects one. No rule changed.

Read [rule precision](../guides/rule-precision.md) before you rely on these numbers. An agent labeled most of the sample and nobody reviewed its labels. Three validated packs are close to the bar. "Validated" covers only the rules that fired on the corpus.

## A smaller shell guard that blocks the same things

Since 0.0.14 a shell command is blocked only when the agent acts on Pregate itself. The code that decided whether a command writes project source no longer blocked or said anything, and it is removed. `src/shell.ts` is 1,992 lines, down from 2,464.

The guard still blocks a write to `.pregate/`, to Pregate state or to harness settings, also through an interpreter one-liner or a literal script; `pregate enable` and `pregate disable`; a switch of a harness's hooks; and an approval variable. Three gaps in those blocks are closed: a terminal-giving wrapper (`script`, `screen`, `tmux`, `expect`) in front of `pregate disable`, a shell with clustered options, and `git -C <dir> commit --no-verify`.

A command with unfinished shell syntax now runs with no note.

## Engine fixes from a code review

- The CI ratchet reports a preset that no longer says `"uncertainty": "closed"`, and a `versionGate` or `when` added to a rule. Both were invisible to it.
- An escaped import specifier (`"\u0066s"` for `fs`) names the module the runtime loads.
- Destructured exports count as the names they bind.
- A value import beside an `import type` of the same module on one line is still a cycle edge.
- A brace group in a layer glob does not outrank a more specific glob.
- A `<script>` inside an HTML comment of a Vue or Svelte file is not read as code.

Two reported items were checked and are not bugs: a `has` relation with a field and a `stopBy` rule gives the same result as ast-grep, and a literal `</script>` ends a script block for the HTML parser too.

## What this release does not establish

- The guided setup still proposes the language pack of the project (`typescript`, `python`, `rust`), and those packs are not validated. In advisor mode their findings inform and do not block.
- A workspace package in a folder that is not named after it, a root package imported by its own name, and the `require` and `node` export conditions are not resolved.
- The precision corpus has no Rust code, and 16 of the 59 rules that fired have no label.
- A non-literal `import(expr)` in TypeScript under a restricted layer is still not reported unless the anti-evasion methodology is on.
- A repository without CI that runs `pregate check --ratchet` has only notes locally.
- The full suite does not run on macOS in CI. macOS runs the latency and release-build jobs there, and the suite on the maintainer's machine. Linux and Windows archives stay experimental until native validation is recorded.
