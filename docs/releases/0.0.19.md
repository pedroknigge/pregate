# Release 0.0.19

**Pregate** `v0.0.19`, core `0.0.1`. macOS ARM64 stays the stable platform. Linux and Windows archives stay experimental until native validation is recorded.

Install 0.0.19 with `pregate update`. If you come from 0.0.13 or older, also run `pregate setup` once. No project needs a step.

## Parser and monorepo resolution fixes

This patch release fixes two verified findings from an outside review of 0.0.18 and improves package `exports` resolution:

- **Unicode escape decoding (`src/ts.ts`):** `unquoted()` now decodes `\u{...}` escapes with arbitrary leading zeros (such as `"\u{0000066}s"` → `"fs"`) and guards `String.fromCodePoint()` against out-of-range code points (`> 0x10ffff`) instead of throwing an uncaught `RangeError`.
- **Fail-closed package `tsconfig.json` (`src/resolve.ts`):** When a package's nearest `tsconfig.json` is invalid, `loadTsPaths()` now returns `"invalid"` instead of falling back silently to the root `tsconfig.json`.
- **Workspace `exports` matching (`src/resolve.ts`):** `exportTargets()` now checks `source`, `development`, `bun`, `node`, `import`, `require`, `default`, and `types`, and selects the longest matching `*` prefix (then longest suffix) rather than the first entry.

## What this release does not establish

- The limits listed in the [0.0.16 notes](0.0.16.md) still apply.
- The full suite does not run on macOS in CI. macOS runs the latency and release-build jobs there, and the suite on the maintainer's machine. Linux and Windows archives stay experimental until native validation is recorded.

The [changelog](../../CHANGELOG.md) lists every change.
