# Release 0.0.1

Initial public open-source release of **Pregate** (`v0.0.1`, core `0.0.1`).

## Highlights

- **Pre-execution AI agent gate** for Claude Code, Cursor, Codex, Grok, and Antigravity (`agy`), plus Git `pre-commit` and CI.
- **Multi-language AST and Tree-sitter analysis** for TypeScript, JavaScript, Vue (`.vue`), Svelte (`.svelte`), Python (`.py`), Go (`.go`), and Rust (`.rs`).
- **44 bundled optional packs and 1,096 total checks** (68 built-in core checks + 1,028 optional checks) covering clean architecture boundaries, pure functional cores, explicit error handling, type discipline, and agent-safety invariants.
- **SHA-256 digest-bound human approval** (`pregate approve <code>`) protecting `.pregate/preset.json`, `.pregate/pregate.lock.json`, and harness hook configurations from silent agent drift.
- **SARIF 2.1.0 output** (`pregate check --format sarif` and `pregate audit --sarif`) and a native **GitHub Action** (`uses: pedroknigge/pregate@3260996631bf29c93caa98fedc8e24d9ec14ffd5 # v0.0.1`).
- **Native standalone binaries** for macOS (`darwin-arm64`, `darwin-x64`), Linux (`linux-x64`, `linux-arm64`), and Windows (`windows-x64`), plus Homebrew (`dist/pregate.rb`) and Scoop (`dist/pregate.json`) manifests. Install from the GitHub release with `install.sh` or `install.ps1`. There is no npm package yet.

## Install

macOS and Linux:

```sh
curl -fsSL https://github.com/pedroknigge/pregate/releases/latest/download/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/pedroknigge/pregate/releases/latest/download/install.ps1 | iex
```

Both scripts come from the [GitHub release](https://github.com/pedroknigge/pregate/releases/tag/v0.0.1). There is no npm package yet.
